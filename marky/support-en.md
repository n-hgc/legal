# MarkyMD Support

Thank you for using **MarkyMD**, a read-only Markdown viewer for macOS.
This page explains how to get help, report bugs, and request new features.

## Contact: Discord Community

The MarkyMD support channel is our community **Discord server**. The server
is open to everyone and free to join — anyone can sign up for a Discord
account at no cost.

[**Join the MarkyMD Discord →**](https://discord.gg/zuvqSC3h6s)

You can use the server to:

- Ask how-to questions about using the app
- Report bugs (please include macOS version, app version, and steps to reproduce)
- Request new features
- Discuss workflows with other MarkyMD users

We aim to respond within 1–2 business days.

## Frequently Asked Questions

### What does MarkyMD do?

MarkyMD is a read-only Markdown viewer designed to sit beside your editor or
AI chat window and quietly display the Markdown that other tools (text
editors, AI assistants, AI chat apps) write to disk. The preview updates
within roughly 500 ms of the file changing on disk.

### Does MarkyMD edit Markdown files?

No. MarkyMD is intentionally read-only. Use a separate Markdown editor for
authoring, and keep MarkyMD open beside it for live preview.

### What macOS versions are supported?

macOS 14 (Sonoma) or later.

### Does MarkyMD send my data anywhere?

No. MarkyMD performs no network communication and collects no analytics.
See the [Privacy Policy](../privacy-policy-en/) for full details.

### How do I add a folder to watch?

Choose **Add Workspace** from the welcome screen or via the menu bar, then
select any folder containing `.md` files. Subfolders that contain a `.git`
directory are treated as individual projects in the sidebar; otherwise the
parent folder itself becomes a single project.

### Does it support Mermaid diagrams and math?

Yes. Mermaid (flowcharts, sequence diagrams, and other diagram types) and
KaTeX (LaTeX-style math) are bundled with the app. Syntax highlighting in
code blocks is provided by shiki.

### How do I close and reopen the main window?

Closing the main window keeps the app running so it can continue watching
your files in the background. To bring the window back, choose
**Window → メインウィンドウを表示** from the menu bar, or click the MarkyMD
icon in the Dock.

## Reporting a Bug

When reporting a bug on Discord, please include the following so we can
reproduce the issue quickly:

1. macOS version (e.g., 14.5)
2. MarkyMD version (shown in **MarkyMD → About MarkyMD**)
3. Steps to reproduce
4. What you expected to happen
5. What actually happened

If the bug involves a specific Markdown file, attaching the file (or a
minimal reproduction) is very helpful.

## Privacy

MarkyMD does not collect, transmit, or share any personal data. See the full
[Privacy Policy](../privacy-policy-en/) for details on data handling and the
third-party libraries bundled with the app.
