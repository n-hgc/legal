# MarkyMD サポート

**MarkyMD** をご利用いただきありがとうございます。本ページでは、ヘルプ、不具合報告、機能要望の連絡方法をご案内します。

## お問い合わせ: Discord コミュニティ

MarkyMD のサポートは **Discord コミュニティ**で行っています。誰でも参加可能・無料で、Discord アカウントも無料で取得できます。

[**MarkyMD Discord に参加する →**](https://discord.gg/zuvqSC3h6s)

Discord サーバーでは以下を受け付けています:

- アプリの使い方に関する質問
- 不具合報告 (macOS のバージョン、アプリのバージョン、再現手順を併記してください)
- 機能要望
- 他のユーザーとの情報交換

返信は 1〜2 営業日以内を目安にしています。

## よくある質問

### MarkyMD は何ができるアプリですか?

MarkyMD は読み取り専用の Markdown ビューアです。エディタや AI チャットの横に置いて、他のツール (テキストエディタ、AI アシスタント、AI チャットアプリ) がディスクに書き出した Markdown を静かに表示することを目的に設計されています。ファイル更新から約 500 ミリ秒以内にプレビューが更新されます。

### MarkyMD で Markdown を編集できますか?

できません。MarkyMD は意図的に読み取り専用としています。編集には別の Markdown エディタを使い、MarkyMD はその横でライブプレビュー用に開いておく使い方を推奨します。

### 対応 macOS バージョンは?

macOS 14 (Sonoma) 以降。

### データはどこかに送信されますか?

いいえ。MarkyMD はネットワーク通信を一切行わず、解析データも収集しません。詳細は[プライバシーポリシー](../privacy-policy-ja/)をご覧ください。

### 監視するフォルダはどう追加しますか?

ウェルカム画面またはメニューバーの「Workspace 追加」を選び、`.md` ファイルを含む任意のフォルダを選択します。`.git` を含むサブフォルダは個別のプロジェクトとして扱われ、`.git` がない場合は選んだフォルダ自体が 1 つのプロジェクトになります。

### Mermaid 図表や数式は表示できますか?

はい。Mermaid (フローチャート、シーケンス図など) と KaTeX (LaTeX 形式の数式) はアプリにバンドルされています。コードブロックのシンタックスハイライトは shiki が担当します。

### メインウィンドウを閉じた後、再表示するには?

メインウィンドウを閉じてもアプリは動作を継続します (ファイル監視のため)。再表示するには、メニューバーから「Window → メインウィンドウを表示」を選ぶか、Dock の MarkyMD アイコンをクリックしてください。

## 不具合報告

Discord で不具合を報告する際は、以下を併記いただくと再現が早くなります:

1. macOS のバージョン (例: 14.5)
2. MarkyMD のバージョン (「MarkyMD → MarkyMD について」で確認可能)
3. 再現手順
4. 期待された挙動
5. 実際の挙動

特定の Markdown ファイルで発生する不具合の場合、そのファイル (または最小再現ファイル) を添付いただけると助かります。

## プライバシー

MarkyMD は個人情報を一切収集・送信・共有しません。データの取り扱いと使用しているオープンソースライブラリの詳細は[プライバシーポリシー](../privacy-policy-ja/)をご確認ください。
