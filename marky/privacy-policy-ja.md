# MarkyMD プライバシーポリシー

**発効日:** 2026年5月4日
**最終更新:** 2026年5月4日

MarkyMD（以下「本アプリ」）は、n-hgc（以下「開発者」）が開発する macOS 用の read-only Markdown ビューアです。本ポリシーは、本アプリがあなたの情報をどのように扱うかを説明します。

## サマリー

**MarkyMD は個人情報を収集・送信・共有することは一切ありません。** 本アプリはネットワーク通信を行わず、すべての処理はあなたの Mac の中だけで完結します。

## アプリがアクセスする情報

本アプリは Markdown ファイルを表示するために、以下の情報にアクセスします：

- あなたが Open Panel で選択したフォルダ（Workspace）配下のファイル / ディレクトリ構造
- 配下にある `.md` ファイルの内容（読み取り専用）
- ファイルの最終更新日時（鮮度バッジの表示およびソート用）

これらは表示のためにメモリ上で読み込まれますが、本アプリが複製・送信・保存することはありません。

## アプリがデバイス内に保存する情報

本アプリは macOS の Application Container 内に、以下の情報のみを保存します：

- あなたが選択したフォルダの再オープン用 Security-Scoped Bookmark
- 表示に関する設定値（常時最前面表示の有無、更新時に前面化するかどうか）

これらは本アプリの基本機能を提供する目的にのみ使用され、デバイス外に送信されることはありません。

## 収集しない情報

- 個人を特定できる情報（氏名・メールアドレス・電話番号・住所等）は **一切収集しません**。
- 解析・テレメトリは **使用しません**。
- アプリ・ウェブサイト間でのトラッキングは **行いません**。
- 広告識別子は **使用しません**。
- 第三者の SDK は **組み込まれていません**。
- ネットワーク経由でのデータ送信は **ありません**。
- クラッシュレポートの自動送信は **行いません**。

## ネットワーク通信

本アプリはネットワーク通信を行いません。Markdown のレンダリングに使用するライブラリ（markdown-it / Mermaid / KaTeX / shiki）はすべてアプリにバンドルされており、外部サーバーから取得することはありません。

ドキュメント中のリンクをクリックした場合、リンクは macOS の標準ブラウザに引き渡されます。本アプリ自身がリンク先に接続することはありません。

## データの保存とバックアップ

本アプリが保存する情報はあなたのデバイス内で完結します。macOS の設定で iCloud Drive または Time Machine 等によるバックアップが有効になっている場合、Apple または OS のバックアップ機構が本アプリのコンテナデータをバックアップに含める可能性があります。これらのバックアップは Apple または OS によって暗号化・管理されており、開発者はアクセスできません。詳細は [Apple のプライバシーに関する取り組み](https://www.apple.com/jp/legal/privacy/) をご参照ください。

## データの削除

あなたはいつでもすべてのデータを削除できます：

- **アプリのアンインストール**：MarkyMD を「アプリケーション」フォルダから削除し、`~/Library/Containers/com.nhgc.marky/` を削除すると、本アプリが保存したすべての情報が削除されます。
- **ターミナルから**：`defaults delete com.nhgc.marky` を実行すると保存された設定値が削除されます。

## お子様のプライバシー

MarkyMD はすべての年齢層にご利用いただけます。13歳未満のお子様（または該当地域に適用される年齢基準）から意図的にデータを収集することはありません。本アプリはそもそも一切のデータ収集を行わないため、この条件は自動的に満たされます。

## 第三者コンポーネント

本アプリは Markdown のレンダリングのために以下のオープンソースライブラリをバンドルして使用しています。これらのライブラリはアプリ内でローカルに動作し、データの収集・送信を行いません：

- [markdown-it](https://github.com/markdown-it/markdown-it)（MIT License）— Markdown パーサ
- [Mermaid](https://github.com/mermaid-js/mermaid)（MIT License）— 図解
- [KaTeX](https://github.com/KaTeX/KaTeX)（MIT License）— 数式
- [shiki](https://github.com/shikijs/shiki)（MIT License）— シンタックスハイライト

## ポリシーの変更

本ポリシーが更新された場合、本アプリの新バージョンおよび本ページに反映されます。発効日も併せて更新されます。
